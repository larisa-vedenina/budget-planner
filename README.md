# Budget Planner

Budget Planner — веб-приложение для планирования личного бюджета. Пользователь задает период, добавляет доходы и расходы, а затем работает с визуальной бюджетной доской, где можно редактировать пункты, менять их приоритет, переставлять и отмечать выполненными.

Публичная версия: [https://ai-budget.ru/](https://ai-budget.ru/)

Статическое зеркало на GitHub Pages: [https://larisa-vedenina.github.io/budget-planner/](https://larisa-vedenina.github.io/budget-planner/)

Примечание: текущая публичная версия размещена на внешнем хостинге. В некоторых регионах сайт может открываться стабильнее через VPN. GitHub Pages-версия работает как статическое frontend-демо без серверных функций.

## О проекте

Проект разработан мною с нуля. Я самостоятельно сформировала идею и пользовательские сценарии, спроектировала интерфейс и визуальную систему, адаптировала приложение для мобильных устройств и реализовала как клиентскую, так и серверную части.

## Статус разработки

Основная клиентская часть приложения уже реализована. AI-генерация стартового плана, SMS-верификация и серверная база данных находятся в процессе разработки и подключения.

## Основные возможности

- стартовая страница, форма создания бюджета, главная рабочая страница, архив и экран входа;
- интерактивное редактирование бюджета с автосохранением;
- drag and drop, приоритеты, настройка цветов секций и undo/redo;
- адаптивный интерфейс для desktop и mobile;
- подготовленная серверная основа для генерации стартового плана и работы с пользовательскими данными.

## Локальный запуск

### Frontend

```bash
cd frontend
npm install
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Backend

```bash
cp backend/.env.example backend/.env
cd backend
npm install
npm start
```

Для серверных возможностей необходимо заполнить переменные окружения в `backend/.env` на основе `backend/.env.example`.
