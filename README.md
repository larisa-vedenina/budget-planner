# Budget Planner - планировщик бюджета с AI-ассистентом

## Основной функционал

- Умный бюджет - Редактируемый бюджет с автоматическим пересчетом остатка

- Гибкий период - Настраиваемые временные рамки с интеллектуальным форматированием

- Приоритеты - Цветовая система расстановки приоритетов

- AI-советы - Автоматические рекомендации по оптимизации расходов

## Технологический стек

### Frontend

React 18 + TypeScript - Основной фреймворк

React Hooks - Управление состоянием

LocalStorage API - Сохранение данных

### Архитектура

ООП подход - Четкое разделение моделей и компонентов

Компонентный подход - Переиспользуемые UI-компоненты

TypeScript - Статическая типизация

## Установка

### Клонирование репозитория
git clone https://github.com/your-username/budget-planner.git
cd budget-planner

### Установка зависимостей
cd frontend
npm install

### Запуск в режиме разработки
npm start

Приложение будет доступно по адресу: http://localhost:3000
