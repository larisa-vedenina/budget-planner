# Budget Planner

Budget Planner — AI-powered веб-приложение для планирования личного бюджета с интерактивной рабочей доской.
Пользователь задаёт период, доходы, расходы, цели, долги и активы, а AI-агент формирует стартовый план бюджета: распределяет траты, выделяет приоритеты и добавляет точные рекомендации без лишней воды.

## О проекте

Проект реализован мной полностью: от формулирования идеи и пользовательских сценариев до проектирования интерфейса и разработки клиентской и серверной частей.

Основной фокус — создание удобного инструмента для работы с бюджетом в формате “доски”, где AI помогает быстро превратить вводные данные в понятный план, а пользователь дальше может гибко редактировать его под себя.

---

## Ключевые возможности

- AI-генерация стартового плана бюджета на основе данных формы;
- расчет обязательных и необязательных расходов с учетом периода, доходов, долгов, активов и целей;
- AI-рекомендации в заметках: лимиты на регулярные траты, подсказки по накоплениям, долгам и резерву;
- создание бюджета с выбором периода и структуры доходов/расходов;
- интерактивная доска с возможностью:
  - редактирования элементов;
  - изменения приоритета;
  - drag-and-drop перестановки;
  - отметки выполнения;
- автосохранение изменений без явного подтверждения со стороны пользователя;
- undo / redo для работы с состоянием;
- настройка визуального представления (цвета секций);
- адаптивный интерфейс (desktop / mobile);
- архив бюджетов;
- личный кабинет с email-верификацией через одноразовый код;
- серверное сохранение активного бюджета и архива.

---

## Технические решения

- **Управление состоянием**
  - реализована логика undo/redo с историей изменений;
  - согласованность состояния при drag-and-drop и редактировании;

- **Интерактивность**
  - drag-and-drop без потери состояния и с корректным обновлением порядка элементов;
  - оптимизация перерисовок при работе с большим количеством элементов;

- **UX-подход**
  - автосохранение как основной сценарий работы;
  - возможность отката изменений;
  - разделение режима просмотра и режима редактирования;
  - email-flow авторизации без пароля;

- **AI-логика**
  - генерация стартового бюджета из данных формы;
  - распределение расходов по секциям;
  - формирование прикладных заметок и рекомендаций;

- **Архитектура**
  - разделение клиентской и серверной логики;
  - серверное хранение пользовательских данных, активного бюджета и архива;
  - интеграция AI-генерации стартового бюджета;
  - email-верификация личного кабинета.

## Локальный запуск

### Frontend

```bash
cd frontend
npm install
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`.

### Backend

```bash
cp backend/.env.example backend/.env
cd backend
npm install
npm start
```
